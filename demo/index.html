SecureReview

A CLI that reviews GitLab merge requests for security risks. Try its real local detection rules here. Everything runs in your browser; your code never leaves this page.

This browser can't run the scanner. Please update to a current browser (on iPhone/iPad: iOS 15 or newer with the latest updates), or run the CLI instead (see “Run it yourself”).

How it works

  1. Your code A merge request diff or a local file
  2. Local detection Pattern rules run on your machine
  3. Raw code stops here
  4. Safe abstract description Issue type, risk, file, line, generic text. No code.
  5. Gemini Optional, CLI only. Explains each finding.
  6. Report Terminal, Markdown or MR comment

Gemini only ever sees the abstract description. Raw source code is never sent to it, and this demo page never contacts Gemini at all.

Run it yourself

You need Node.js 22 or newer and Git. No GitLab account is needed for the first steps.

Quick start

git clone https://github.com/TomNguyen132006/secure-review.git
cd secure-review
npm ci
npm test
npm run demo

npm run demo scans examples/vulnerable.diff and reports a hardcoded password, a SQL injection and weak authentication.

Scan your own changes offline

git diff main > changes.diff
node bin/secure-review.js scan --diff-file changes.diff

Real GitLab use

Create a GitLab personal access token with the read_api scope (or api if you also want --comment), then: 

node bin/secure-review.js gitlab login
node bin/secure-review.js scan --project my-group/my-project --mr 42
node bin/secure-review.js scan --project my-group/my-project --mr 42 --markdown --comment

Set GEMINI_API_KEY to add AI explanations. Without it, the CLI uses its built-in explanations and says so.

Use it as a CI gate

node bin/secure-review.js scan --project my-group/my-project --mr 42 --fail-on high
Exit codeMeaning
0Success. With --fail-on, no finding reached the level.
1Error (missing option, not logged in, GitLab error, …).
2At least one finding is at or above --fail-on.
130gitlab login was cancelled with Ctrl+C.
